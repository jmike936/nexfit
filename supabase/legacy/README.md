# Schema legado

`legacy_musculacao_schema.sql` é uma cópia de `supabase-musculacao.sql`. Ele cria o modelo antigo de fichas (`workout_plans`, `workout_exercises`, etc.), distinto do modelo atual `training_programs`.

Foi preservado para referência e eventual recuperação histórica, mas não faz parte da sequência de instalação do NEXFIT atual. Não aplicar em um projeto novo sem uma decisão explícita de migração do legado.
